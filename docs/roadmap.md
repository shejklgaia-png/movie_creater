# Movie Creator 開発ロードマップ

## 製品方針
- **Android縦画面を最優先**。PC版は同じGodotプロジェクトから派生させます。
- Blockbenchで制作した3Dモデル・既存モーションを活かし、ゲームのムービー演出をスマホで編集できるソフトを目指します。
- 元の`.bbmodel`を改変せず、Movie Creator独自の編集データを別管理します。
- Godot 4.7.2 / GL Compatibility。操作性・再生位置・関節階層の再現性を優先します。

## 実装済み（Ver.0.1〜0.7）
- Androidでの基本3D表示、タッチによる視点回転／ピンチ、モデル選択・移動・回転・拡縮、XYZ操作ガイド。
- `.bbmodel`のキューブ・自由形状メッシュ・グループ・ピボット・埋め込みテクスチャ・既存アニメーション読み込み。
- タイムライン：モデル全体の移動・回転・拡縮キー、モデル別モーションクリップの配置／IN・OUT／速度／関節マスク、カメラキー。
- 編集視点／撮影カメラの切り替え、カメラ位置キーフレーム。
- **Ver.0.6：選択関節のポーズ補正を時刻別に記録／補間。ポーズON/OFF、選択関節のTLキー表示とドラッグ時刻移動、関節編集のUndo/Redo（40件）、プロジェクトv4で保存／復元。**
- **Ver.0.7：** 狭いAndroid縦画面向けのレイアウト修正、TL時間軸拡大・縦スクロール、モデル削除・新規作成、1〜600秒の尺変更、バックアップ付き自動保存と外部JSONインポート／エクスポート。
- **Ver.0.7：** Cam 1～Nの独立キーフレーム、カット区間バー、タイムラインでのカット移動、撮影プレビュー切り替え。
- **Ver.0.7（基盤段階）：** Godotゲーム用の軽量JSON書き出しと`addons/movie_creator_runtime/`内の再生・シーク・スキップ処理。モデルの自動取込や元モーションへの接続は別途必要。
- Godotヘッドレス統合テスト、AndroidデバッグAPK CI。

## Ver.0.8 開発中（ゲームへの自動接続・第一段階）
- ランタイムJSONにBlockbenchアニメーションの**元の名前・関節UUIDから相対パスへの対応**を追加。元の`.bbmodel`のサイズを含めずに接続情報を出力します。
- Godotゲームシーンのモデルへメタデータ`movie_creator_id`を設定すると、`auto_bind_scene()`でモデルをまとめて接続できます。同じIDが複数ある場合は誤接続を防ぐため拒否します。
- 直下／配下の`AnimationPlayer`が一つであれば、名前で対応する元モーションを自動選択してシークします。関節UUIDのパスマッピングが成立するNode3Dアニメーションでは除外関節を基準姿勢に戻します。繰り返しシーク／停止時も姿勢を保持しません。
- **残課題：** Skeleton3Dのボーントラック、複数AnimationPlayer、別名や別階層へリターゲットしたモデル、演出イベント／音声／動画、実機での再生完全一致。これらは本段階で完成扱いにしません。

## 次に開発する機能（優先順）
1. **ゲーム再生の完成**：ムービーJSONをゲームのBlockbenchモデル／AnimationPlayerへ自動結合。カメラとモデルのローカル・グローバル座標を含め、完成映像とゲームの再生を一致させること。
2. **演出イベントとシーケンス制御**：音声、セリフなし演出、オブジェクト表示／非表示、攻撃エフェクト、スキップ後の状態確定。
3. **ファイル入出力の充実**：GLB/glTF・音声読込、ファイル参照管理、素材欠落チェック。
4. **編集操作の改善**：全体Undo/Redo、キーの複製・削除、クリップのリップル移動、スナップ、レイヤー操作、階層検索。
5. **高度なモーション制作**：IK/FK、関節のカーブ補間、複数モーションの同時再生／クロスフェード、制約・接触補正。
6. **表現と出力**：BGM・字幕、照明・エフェクト、ムービー動画出力、プレビューの負荷計測。

## 注意事項
- Ver.0.7の関節キーフレームは元アニメーションへの**加算型ポーズ補正**です。オリジナルのBlockbenchアニメーションの編集・書き戻し、IK・元モーションの書き戻しは未実装です。カメラカットとゲーム用データの書き出しは追加していますが、モデルの自動バインド／動画出力は未実装です。
- Androidの実機操作は自動テストで代替できないため、APKでの確認を引き続き行います。
- SERA／Pocket Districtなど他のゲームリポジトリは改変しません。
