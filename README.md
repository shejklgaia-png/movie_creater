# 🎬 Movie Creator

Android **縦画面**を最優先に開発する、ゲーム用3Dムービーシーン編集アプリです。Godot 4.7.2を使用します。PCでもマウス操作できます。

> **開発段階: 0.6 プロトタイプ** — 現在は3D配置・要素ごとの移動/回転/拡縮・トランスフォームのキーフレーム・タイムライン・保存/読込に対応しています。GLBの直接読み込み、音声、カメラカット、Godotゲームへの出力は未実装です。カメラのキーフレームとアニメーションクリップのタイムライン管理に対応しました。Blockbenchのキューブ・自由形状メッシュ（mesh）の.bbmodelを読み込めます。APKはGitHub Actionsでビルドされます。

## 起動する

1. Godot **4.7.2** で本リポジトリの `project.godot` を開きます。
2. F6ではなく、F5（メインシーン起動）でアプリを実行します。
3. GitHub Actionsの **Android APK (debug)** の成果物でAPKを配布します。PCからエクスポートする場合はGodotとAndroid SDKが必要です。

## 操作

| --- | --- | --- |
| 視点回転 | **何もないところ**を1本指でドラッグ | 空白の左ドラッグ |
| 視点ズーム | 2本指ピンチ | マウスホイール |
| 視点の平行移動 | 2本指で同時ドラッグ | （未対応） |
| BBModel読込 | **BB読込**からAndroid標準のファイル選択画面で`.bbmodel`を選ぶ | 同じ |
| モデル選択 | 3Dモデルをタップ、またはモデル欄で選択 | モデルをクリック、またはモデル欄で選択 |
| 要素選択 | 部位をタップ／「階層」からグループ・メッシュを個別選択 | 同じ |
| 操作変更 | **プレビュー右下**の「選択／移動／回転／拡縮」をタップ | 同じ |
| 3軸ガイド | 赤=X・緑=Y・青=Z。ガイドの外側をドラッグして軸指定 | 同じ |
| モデル・部位の拡縮 | 「拡縮」モードで縦ドラッグ。軸制限では一方向だけ拡縮 | 同じ |
| 数値編集 | 下部「数値」から対象の位置・回転・倍率X/Y/Zを直接指定 | 同じ |
| 部位のリセット | 「戻す」で選択部位の調整をリセット | 同じ |
| モデルの移動 | **モデルを指で直接ドラッグ**（自由＝水平面移動、X/Y/Z制限あり） | モデルを左ドラッグ |
| モデルの回転 | 「回転」に切替後、モデルを左右にドラッグ | 同じ |
| 精密調整 | 「自由/X/Y/Z」を選択して－/＋ | 同じ |
| 時刻指定 | タイムラインをスワイプ、またはスライダー | 同じ |
| キーフレーム登録 | **モデルのドラッグ終了時に自動登録**／◆で手動登録 | 同じ |
| キーフレームの時刻移動 | タイムラインの◆を左右へドラッグ | 同じ |
| アニメーション配置 | BBモデルを選択し「＋アニメを配置」からクリップを追加 | 同じ |
| 動作クリップ移動 | TL内の青いバーを左右ドラッグ | 同じ |
| 動作クリップ詳細 | 青いバーをタップしIN/OUT、開始時刻、速度、関節ごとの適用を設定 | 同じ |
| 関節のON/OFF | クリップ詳細の関節一覧で選択。親を切替えると子も一括切替 | 同じ |
| 編集／撮影カメラ | 「編集視点」ボタンをタップして切替 | 同じ |
| 撮影カメラ位置登録 | 編集視点を調整後「視点→撮影」を押して時刻に登録 | 同じ |
| カメラキー更新 | カメラを選択・調整し「カメラ◆」で記録 | 同じ |
| 再生 | ▶ | 同じ |
| 保存・読込 | 上部「保存」「読込」 | 同じ |

**移動操作:** 画面下の「移動 ↻ / 回転 ↻」で操作を切り替えます。「自由 ↻」では床と平行なX/Z方向に動きます。「Y ↻」でドラッグすれば高さを調整できます。回転モードの「自由」はY軸回転です。モデルを指で動かすと、指を離した時刻にキーフレームが登録されます。背景をドラッグしてもモデルは動かず、視点だけが回ります。

**最初のサンプル:** 箱・球を配置した状態で始まります。0秒で初期キーが登録されます。時刻を5秒に移し、モデルを動かして「◆ キー登録」すると、0秒から5秒まで補間再生されます。

### Blockbench (.bbmodel) インポート

- Androidの「BB読込」をタップし、ファイル選択画面から `.bbmodel` または `.json` を選びます。
- **現時点の対応：** cuboid/キューブ、**自由形状メッシュ（頂点/面・三角形分割）**、個別面UV、埋め込みPNG/JPEG、グループ親子階層、グループ/キューブ/メッシュの原点と回転、位置/回転/スケールの基本アニメーション（線形／ステップ補間）。
- Blockbench 5.0形式（`groups` と `outliner` 分離）と旧形式のグループ階層を想定しています。
- **現在の制限：** Box UV自動展開、モーションのBezier/Catmull-Rom曲線、Molang式、外部ファイル参照のテクスチャ、テクスチャアニメーション等は未対応または不完全です。
- モデルにテクスチャがない場合は、Blockbenchの要素カラーに対応する代替色を表示します。スキンの質感・複雑なマテリアルは完全再現されません。
- 外部画像は事前にBlockbenchでモデルへ埋め込んで保存してください。
- 読み込んだモーションをクリップとしてタイムラインに配置し、適用する関節をグループ単位で選べます。**個々の関節の姿勢・キーフレームそのものの編集は未実装**です。
- モデルの位置・角度などの編集結果は元の.bbmodelへ上書きせず、このアプリのプロジェクトとして保存します。

### データ保存

アプリのローカル領域 `user://movie_project.json` にJSONを保存します。読み込んだbbmodelの内容（埋め込みテクスチャ含む）もプロジェクト内に保存するため、アプリを再起動しても復元できます。Androidではアプリ専用領域のため、現時点では「ファイルを共有」や端末上の任意ファイル選択は未対応です。アプリのデータを消すと保存内容も失われる可能性があります。

## 制限事項

これは初期実装です。Android実機でのファイル選択・操作はまだ確認できていません。Godot CIの形式・操作テストで検証しています。複数選択、Undo/Redo、GLBインポート、元モーションの関節カーブ直接編集、複数クリップ間のクロスフェード、ムービー出力は今後追加します。

### バグ修正：自由メッシュしかないモデルが読み込めない

Ver.0.3以前は`elements[].type == "cube"`だけを描画していたため、`mesh`だけのモデルで「表示できるキューブがありません」と表示されていました。Ver.0.3.1で`mesh`を含む3Dモデルを受け付けます。テスト用の合成モデルで18個のメッシュ、134面（252三角形）、16グループ、アニメーションとプロジェクト保存を検証済みです。ユーザーの元モデル自体はリポジトリに公開していません。

### Ver.0.3.2：脚・関節がズレる問題の修正

- Blockbenchでの**グループ（ボーン）の回転順序はZYX**、メッシュ・キューブ単体の回転順序はXYZに分けました。これまで両方にXYZを使用していたため、X/Y/Zを同時に回す脚のモーションが正しく再現できず、特に足先位置が大きくずれていました。
- ユーザーが提供したビットタランの元モデルの多軸キーフレームを解析し、旧回転順序との姿勢差を確認しました（元データ自体はリポジトリへ追加していません）。
- GitHub Actionsの独立テストで `Rz * Ry * Rx` とGodotのボーン姿勢、子関節位置、元姿勢への復帰を検証します。
- **Android実機におけるビットタランの最終見た目は別途確認が必要**です。

### Ver.0.3.3：Android縦画面の表示名・カメラ操作修正

- Androidファイルピッカーの `content://` URIはモデル名として表示しません。Blockbenchファイル自身の `name`（例：ビットタラン）を最優先し、保存したプロジェクトを再読込しても短い名前を復元します。
- モデル選択・モーション切替・ステータス表示の長い文章を切り詰め、ボタンに幅制限を設定しました。モデル選択画面も長い名前を省略します。
- モデルをタップしただけではカメラ視点・注視点を変更しません。意図せず視点が飛びやすい細かな指の動きを無視し、2本指パンも急な移動量を制限します。
- 新しい「注視」ボタンをタップした場合のみ、選択モデルへカメラの注視点を合わせます。
- BBModel読み込み時は既存アニメーションを反映した後の姿勢を基準に一度だけ画角を合わせます。大型モデルの黄色い選択枠は非表示です。
- 新しい自動テスト `test_mobile_ui_stability.gd` で、URI非表示、ボタン幅、カメラ安定、表示名保存を検証しています。

**注意:** 実機上での細かなタッチ感度は端末により異なるため、最終確認はAndroidでの操作が必要です。

### Ver.0.4：カットシーン用タイムラインと撮影カメラ

1. モデルを読み込むと、最初のモーションが0秒から青い**アニメバー**として配置されます。
2. 「＋アニメを配置」でモデルに含まれる別のモーションを追加できます。現在のTL時刻から開始されます。
3. 青いバーの**ドラッグ**で開始時刻を移動できます。**タップ**で詳細画面を開き、元のモーションのIN/OUT（秒）、再生速度（0.1～4倍）、使用する関節を指定できます。
4. 詳細画面で「全関節OFF」にしてから腕のグループをONにすると、選択したグループとその子だけにモーションが適用されます。複数のクリップが同じモデル上で重なった場合は、開始時刻が後のものが優先されます。**クロスフェードは未実装**です。
5. モデルの位置・回転は従来のキーフレームで独立して動き、アニメーションクリップと組み合わせられます。
6. 「編集視点」と「撮影視点」を切り替えられます。編集カメラを動かして「視点→撮影」を押すと、その位置と角度を**撮影カメラのキー**として現在時刻に登録します。TLの「🎥カメラ」行にはキーが表示され、ドラッグで時刻を変更できます。
7. モデル選択メニューに「撮影カメラ」があり、軸ごとの数値調整ボタン、モデルと同様のドラッグ操作、「カメラ◆」からキーを記録できます。カメラプレビューではカメラ用ハンドルは表示されません。
8. 保存形式v2にアニメバー・関節選択・カメラキーが含まれます。旧v1プロジェクトも読み込み、既存の選択モーションを0秒開始のバーに変換します。

Android実機でのタッチ操作は別途確認が必要です。静止カメラのカット切替、ゲーム再生ランタイム、動画出力は未実装です。

### Ver.0.5：スマホ用モデリング操作

3Dプレビュー**右下**に「選択・移動・回転・拡縮」を横一列で配置しました。モデルとBlockbenchグループ・メッシュの区別ができ、指でパーツをタップして対象を選びます。「階層」でモデル全体と個々のパーツを切り替えられます。

- **移動：** ドラッグで位置変更。自由モードは水平面、X/Y/Zボタンで軸制限。3Dの軸ガイドの先端側を掴んで動かしても軸を指定できます。
- **回転：** ドラッグ量で回転。自由時はY軸、XYZ指定時はその軸。3DにはXYZ色分けの回転ガイドを表示します。
- **拡縮：** 上方向へドラッグで拡大、下方向へドラッグで縮小。自由時は均等拡縮、軸指定時は個別拡縮。
- **数値編集：** 下部「数値」から位置・回転・拡縮倍率を3軸で指定できます。「＋／－」は従来通り細かな調整です。
- **保存：** モデル全体の拡縮はキーフレームに記録されます。Blockbenchの個々のグループ・メッシュ編集は、元アニメーションに**加算する補正値**として保存されます。元の`.bbmodel`を直接上書きしません。これは現時点では全時刻共通の調整です（**ポーズ記録ONで部位独自のキーフレーム編集に対応**）。
- **プレビュー：** 既存の2本指ピンチによるカメラ拡大縮小を維持しています。拡縮モード中でも2本指はモデル拡縮ではありません。
- **保存形式：** v3（旧v1/v2との読み込み互換）。静的メッシュ要素の調整が再生位置の移動ごとに累積しないよう、基準姿勢を再適用しています。
- **制限事項：** 頂点・辺・面の追加削除、押し出し・切断、テクスチャペイント、複数要素一括変形、IK、ボーン個別キーフレーム編集、Undo/Redo、Godotへのシーン書き出しは**まだ未実装**です。

この版は3Dモデリングソフトに必要な**基本トランスフォーム編集**を先に実装したものです。本格的なメッシュ形状編集機能はこれから追加します。

### Ver.0.5.1：3D操作ガイドのモデル追従修正

- モデル全体を選択した場合、Blockbenchモデルの原点が形状から離れていても、モデルの**形状中心に固定したローカル位置**にXYZガイドを配置します。腕や脚が動くたびに中心位置を再計算して跳ねることはありません。
- グループ・関節・個別メッシュを選択した場合は、その要素の**回転中心（ピボット）**にガイドを配置します。アニメーション再生・タイムライン移動に追従します。
- **指でドラッグしている最中**にも移動・回転・拡縮が軸ガイドへ即時反映され、指を離すまで古い位置に取り残されません。
- XYZガイドの向きは選択した要素の**ローカル座標軸**に追従します。回転した親グループの下でも、軸ハンドルをドラッグした方向と実際の移動方向を一致させます。
- 視点の回転・ズーム中もガイドを更新し、画面上のおおむね一定の大きさを維持します。撮影視点では非表示です。
- Godot統合テスト `tests/test_gizmo_follow.gd` で上記の追従とピボット・ドラッグを検証しています。Android実機での指操作は別途確認が必要です。

### Ver.0.6：関節単位のポーズキーフレーム

既存のBlockbenchアニメーションに、**関節のポーズ補正を時間ごとに追加する機能**を実装しました。キーフレームは元の`.bbmodel`に書き戻さず、Movie Creatorのプロジェクトに保存されます。

1. 「BB読込」でモデルを開き、「階層」または3D画面から腕・脚などのグループを選びます。
2. 「◆ポーズOFF」を押して「◆ポーズON」に切り替えます。
3. 0秒で「◆ キー登録」を押すと、その時刻の現在のポーズ補正が登録されます。
4. タイムラインを2秒などに移し、プレビュー右下の「移動・回転・拡縮」で関節をドラッグすると、指を離した時刻に自動で◆が追加されます。「数値」編集も記録されます。
5. TL下部の**選択した関節専用の◆トラック**にキーが表示され、左右のドラッグでタイミングを変更できます。
6. キー間は位置・拡縮が線形補間され、回転は短い角度方向で補間されます。元アニメーションの関節姿勢は保持され、編集値が上乗せされます。
7. 「◆ポーズOFF」では従来の**全時刻共通の補正**を行います。ON時の「戻す」は現在時刻のポーズキー削除、OFF時の「戻す」は共通補正のリセットです。
8. 上部の「↶」「↷」で**関節編集の操作**を40件まで取り消し・やり直しできます。現在は関節の移動・回転・拡縮、キーの登録・削除が対象で、モデル全体やカメラの全操作までの共通履歴ではありません。
9. プロジェクト形式v4として保存・読込。v1～v3の旧プロジェクトを開くことも可能です。

**制限事項:** この版のポーズキーは加算・倍率補正です。Blockbench本来のアニメーションキーフレームそのものの書き換え、IK制御、複数クリップのレイヤー合成、動画/Godotランタイム出力は今後の開発対象です。Android実機の操作感は別途確認が必要です。
