# 🎬 Movie Creator

Android **縦画面**を最優先に開発する、ゲーム用3Dムービーシーン編集アプリです。Godot 4.7.2を使用します。PCでもマウス操作できます。

> **開発段階: 0.1 プロトタイプ** — 現在は3D配置・トランスフォームのキーフレーム・タイムライン・保存/読込に対応しています。GLBの直接読み込み、音声、カメラカット、Godotゲームへの出力、Android APK配布は未実装です。

## 起動する

1. Godot **4.7.2** で本リポジトリの `project.godot` を開きます。
2. F6ではなく、F5（メインシーン起動）でアプリを実行します。
3. Android版はGodotのAndroid export templatesとAndroid SDKを準備し、`project.godot` からAPKへエクスポートします。現状ではビルド済みAPKを配布していません。

## 操作

| 操作 | Android | PC |
| --- | --- | --- |
| 視点回転 | プレビューを1本指でドラッグ | 左ドラッグ |
| 視点ズーム | 2本指ピンチ | マウスホイール |
| モデル選択 | 3Dモデルをタップ、またはモデル欄で選択 | モデルをクリック、またはモデル欄で選択 |
| モデルの編集 | 「移動/回転」「X/Y/Z」を選択して－/＋ | 同じ |
| 時刻指定 | タイムラインをスワイプ、またはスライダー | 同じ |
| キーフレーム登録 | ◆ キー登録 | 同じ |
| キーフレームの時刻移動 | タイムラインの◆を左右へドラッグ | 同じ |
| 再生 | ▶ | 同じ |
| 保存・読込 | 上部「保存」「読込」 | 同じ |

**最初のサンプル:** 箱・球を配置した状態で始まります。0秒で初期キーが登録されます。時刻を5秒に移し、モデルを動かして「◆ キー登録」すると、0秒から5秒まで補間再生されます。

### データ保存

アプリのローカル領域 `user://movie_project.json` にJSONを保存します。Androidではアプリ専用領域のため、現時点では「ファイルを共有」や端末上の任意ファイル選択は未対応です。アプリのデータを消すと保存内容も失われる可能性があります。

## 設計とソース

- `scripts/editor.gd`: UI、3Dプレビュー、オブジェクト管理、タイムライン再生、保存・読込
- `scripts/timeline.gd`: 縦画面向けタイムライン描画・タッチ編集
- `scenes/editor.tscn`: メインシーン
- `docs/roadmap.md`: 次の開発段階
- `.github/workflows/godot-check.yml`: Godotヘッドレス検証

既存の**SERA**および**Pocket District**リポジトリには変更を加えません。
